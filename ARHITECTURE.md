# Архитектура системы кредитного скоринга

## Обзор
Промышленная система кредитного скоринга с полным MLOps-циклом.

## Компоненты системы

### 1. Модель машинного обучения
- Нейронная сеть (3 слоя, 64-32-16 нейронов)
- Формат: PyTorch → ONNX → Quantized ONNX

### 2. Микросервисная архитектура
- **API Service**: FastAPI приложение для инференса
- **Training Service**: Сервис переобучения моделей
- **Monitoring Service**: Мониторинг дрифта и метрик

### 3. Инфраструктура
- **Kubernetes Cluster**: Managed Kubernetes в Yandex Cloud
- **Node Groups**: 
  - CPU-пул (4 ядра, 8GB RAM)
  - GPU-пул (для тренировки моделей)
- **Storage**: Object Storage для моделей и данных
- **Networking**: VPC с security groups

### 4. CI/CD Pipeline
- **GitHub Actions**: 
  - Security scanning (Trivy, Bandit)
  - Тестирование (unit, integration)
  - Сборка и push Docker образов
  - Деплой (Blue-Green стратегия)

### 5. Мониторинг и Observability
- **Prometheus**: Сбор метрик
- **Grafana**: Дашборды
- **Loki**: Централизованное логирование
- **Alertmanager**: Алертинг

### 6. Управление моделями
- **MLflow**: Трекинг экспериментов
- **Evidently AI**: Мониторинг дрифта
- **Airflow**: Пайплайны переобучения

## Безопасность
- RBAC в Kubernetes
- Secrets management через Vault
- Network policies
- SSL/TLS шифрование
- Security scanning в CI/CD

- Horizontal Pod Autoscaling (HPA)
- Cluster Autoscaler
- Redis кэширование
